# Product copy guide

## Prefer

| Instead of | Use |
|------------|-----|
| Begin Assessment | Start quiz / Continue quiz |
| Rules & Guidelines | Before you start |
| Submission Successful | Here’s how you did |
| Flagged for cheating | Needs review |
| SENT / DUPLICATE | Invite sent / Already invited |
| Score: 80 | 80 · Passed / 80 · Not yet |

## Tone

- Learner: calm, clear, one next step.
- Admin: operational, action-oriented, never accusatory about integrity.
- Empty states always include one CTA.
